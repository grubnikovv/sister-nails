# Сайт сестры Владислава — «Мэй’Эйлин»: ногтевая академия и нейл студия

Сестра — Алина Грубникова (ИП, ИНН 345600043182). Сайт объединяет студию (услуги для клиенток: онлайн-запись,
подарочные сертификаты, кабинет клиентки — как у мамы) и академию (онлайн/офлайн-курсы для учениц).
Логотип студии — `img/logo.webp` / `img/logo-dark.webp` (вырезан из присланного PNG, форму не менять, только тон).
Цвета и тексты взяты с её сайта на Тильде (academynail.tilda.ws, копия — `references/tilda/`): серый #E6E7E8,
пудрово-розовый #FFBEED, тёмно-синий #01142F, фуксия #FF008B.

Обучение (требования владельца): уроки открываются по мере прохождения курса; домашние задания (фото/текст)
с проверкой Алиной (принять / вернуть на доработку с комментарием); связь с куратором (чат в кабинете + уведомления в Telegram).

Основа взята с сайта мамы «М.А» (ma-nails.ru, репозиторий grubnikovv/ma-nails): онлайн-запись, личные кабинеты клиенток,
кабинет мастера, сертификаты, Telegram-бот, письма, редактор каталога (карандаш ✎). Отличия этого проекта:
- **Онлайн-курсы вместо очных.** Видеоуроки прямо на сайте, доступ к курсу открывается после оплаты (в личном кабинете).
- **Нормальная онлайн-оплата через интернет-эквайринг** (банк ещё не выбран: ЮKassa / Т-Банк / Робокасса и т. п.).
  Никаких «переведите по СБП и напишите мастеру» — оплата на сайте, статус приходит от банка (webhook), чек — от кассы банка.
- Владелица — ИП на НПД (самозанятость). Чеки через сервис банка/кассы, с передачей в «Мой налог», если банк это умеет.

## Текущее состояние (решения владельца)
- Рабочий прототип — `v2/` (SPA на hash-маршрутах, демо-данные в localStorage): https://grubnikovv.github.io/sister-nails/v2/ (ветка `design-v1`, превью через GitHub Pages).
- Логотип (v4): надпись «Мэй’Эйлин» целиком гель-лаком, вырезана из генерации (`references/logo/mayeilin-lak-v2-original.jpg`), форму не менять. Цвет как у слова «мастера»: светлая тема #C8006A (`img/me-word-l.webp`), тёмная #FF6CB4 (`img/me-word-d.webp`), переключаются CSS `.wm--l/.wm--d`. Иконки и заставка — отдельная «М» (`img/me-mm*.webp`). PNG без фона — `references/logo/`.
- Цвета: светлая тема — бумага с визитки (#F0E9DF + фактура `img/grain.webp`), тёмно-синий логотипа #0E1A33, фуксия; тёмная тема — графит (#1E1D1F), не синий. Переключатель темы в шапке/меню/кабинетах; всё должно корректно меняться в обеих темах.
- Записи в студию и подарочные сертификаты с сайта убраны: все «Записаться» ведут на DIKIDI (`A.DIKIDI` в `v2/js/core.js` — подставить ссылку Алины). Сертификат об окончании курса остаётся частью обучения.
- Обучение: модули, плеер-заглушка (Алина вставит видео), таймкоды, материалы; типы уроков — теория (отметить «изучен»), тест (автопроверка, ≥2/3), задание (проверка Алиной: «Отправить → Проверка → Принято»). Тип каждого урока Алина выбирает в CRM → «Курсы». Демо-программа — `v2/js/program.js`.
- Фото: открываются на весь экран (просмотрщик), в чате можно отправлять фото.
- Вход: только почта (ссылка для входа) + VK ID и Яндекс ID (OAuth на сервере при переезде на хостинг). Вход по телефону отключён. При покупке обязательна почта (туда доступ и чек) и галочка согласия (оферта + ПДн). VK/Яндекс можно привязать в кабинете. «Выйти» пока ведёт на главную.
- Документы: `#/dokumenty` (оферта, политика, согласие, условия возврата, реквизиты) — тексты Алины с Тильды (`v2/js/docs.js`), PDF в `v2/docs/*.pdf` (генерируются из `v2/docs/print.html` через Playwright). Баннер cookie.

- Админка (CRM → «Курсы» и «Сайт», файлы `v2/js/cms.js` + `v2/js/admin.js`; правки хранятся в localStorage `as-cms`, на сервере — в БД через API):
  - Курсы: добавить/удалить/скрыть/порядок, название, формат, уровень, цена, старая цена, «Выгодно», описание, факты, условия, обложка, 6 фото работ учениц (пустые места на сайте — рамки «Фото появится здесь»).
  - Программа: модули и уроки (добавить/удалить/порядок), тип урока, длительность, «вопросы куратору» открыты/закрыты по уроку, описание, пункты, таймкоды, материалы (PDF), задание и критерии, тест (вопросы и верные ответы), видео.
  - Сайт: режим правки любых текстов и фото прямо на страницах (Главная, Академия, Студия, Об Алине, Контакты, Документы), контакты и ссылка DIKIDI, услуги и цены студии, портфолио.
  - На сервере: загрузка видео любого формата с перекодированием в 1080/720/480 (HLS, ffmpeg) и выбором качества в плеере; хранение PDF; заявки/оплаты/ученицы из админки не редактируются задним числом.
- CRM: видимых ссылок на сайте нет. Тайная дверь — удерживать «©» в подвале ~1 с (`#cpr` в `v2/index.html`, обработчик в `A.start`). Прямой адрес `#/crm`. На сервере добавить пароль + код в Telegram и noindex.

## Как общаться с владельцем
- Только по-русски, коротко и по шагам. Владислав работает с телефона, кодом не владеет: никаких действий, требующих компьютера.
- Всё, что нужно сделать руками, — пошагово, с готовым текстом для копирования.
- Перед выкладкой на хостинг — показать результат (скриншоты/видео) и спросить.

## Правила
- Персональные данные клиенток (имена, телефоны, почты, записи, копии базы) никогда не попадают в git.
- Секреты (токен бота, пароли FTP/почты, ключи эквайринга) не просить в чате — только GitHub Secrets / config.php на хостинге.
- Проверка перед показом: телефон 320/390 и ПК 1440, светлая и тёмная тема, без горизонтальной прокрутки и ошибок в консоли; проверять сжатую сборку.
- Оплата только легально (ИП/НПД, эквайринг банка). Криптовалюту не предлагать.
- Скорость: чистый HTML/CSS/JS, WebP, lazy-загрузка, анимации на transform/opacity, уважать prefers-reduced-motion. Премиальный дизайн — уровень профессионального дизайнера.
